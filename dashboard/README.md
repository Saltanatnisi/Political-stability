# ИПУ-КР — Дашборд Индекса политической устойчивости Кыргызской Республики

Интерактивный аналитический дашборд, реализующий архитектуру и расчётные формулы «Методики оценки
политической устойчивости Кыргызской Республики в период президентского избирательного цикла
2026–2027 годов» (файл `../Политичекая_устойчивость_государства[1].md` в корне репозитория).

## Что реализовано

- **10 аналитических блоков / 100 индикаторов** (Глава 2–3 Методики) с весовыми коэффициентами.
- **Расчётные формулы Главы 4**: значение индикатора, значение блока `Б`, интегральный индекс
  `ИПУ-КР = Σ(Бᵢ × Весᵢ)`, коэффициент политического риска `КПР = 100 − ИПУ-КР`, коэффициент
  кризисного события `ИПУₖ = ИПУ × Ккс`, коэффициент динамики `Кд`, прогноз `ИПУпр = ИПУт + Кд`,
  региональный индекс `РИ = (Б₁+…+Б₁₀)/10`.
- **Шкала уровней устойчивости и «политический светофор»** (п. 4.9–4.11, 10.7).
- **5 сценариев развития ситуации** (Глава 9): стабильный, конкурентный, напряжённый, кризисный,
  форс-мажорный — с автоматическим определением текущего сценария по значению индекса.
- **Региональные паспорта** для 7 областей и городов Бишкек/Ош (Глава 7–8): рейтинг, тепловая
  карта, разбивка по 10 блокам.
- **Обзорная панель**: гейдж интегрального индекса, KPI (риск, сценарий, динамика, светофор),
  радар-диаграмма блоков, график динамики и прогноза, слабые места мониторинга.
- **Интерактивное моделирование**: значения всех 100 индикаторов на национальном уровне можно
  редактировать слайдерами — индекс, блоки и риск пересчитываются в реальном времени.

Первичные данные являются демонстрационными (генерируются локально). В производственном контуре
данные должны поступать из государственных информационных систем, ЦИК, Нацстаткома, социологических
исследований и модуля Political Stability AI согласно Приложениям А, Ж, Л Методики.

## Технологии

React 19 + TypeScript + Vite + Tailwind CSS v4 + Recharts + lucide-react.

## Запуск

```bash
npm install
npm run dev      # локальный dev-сервер
npm run build    # production-сборка (tsc + vite build)
npm run lint      # oxlint
```

## Структура

```
src/
  data/methodology.ts   — модель данных методики (блоки, индикаторы, регионы, сценарии, шкалы)
  lib/calculations.ts   — расчётные формулы (Глава 4)
  lib/mockData.ts       — генератор демонстрационных данных
  hooks/useIpuData.ts   — состояние дашборда и производные вычисления
  components/           — переиспользуемые UI-компоненты (гейдж, радар, тренд, светофор и т.д.)
  pages/                 — вкладки дашборда: Обзор, Блоки и индикаторы, Регионы, Сценарии, О методике
```
